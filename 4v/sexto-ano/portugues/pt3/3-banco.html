2.551.
Leia a frase: “A formiga atravessou a trilha devagar.” Quanto ao gênero, o substantivo destacado é: Responda com a letra.
a) comum de dois gêneros
b) biforme (uma forma para cada gênero)
c) sobrecomum
d) heterônimo (o feminino é outra palavra)
e) epiceno
Ver a resolução
1

Como pensar: faça o teste prático: troque o artigo e veja se a palavra aceita. Depois pergunte se é pessoa ou bicho.

2

“formiga” é epiceno: nome de bicho com uma forma só; o sexo se mostra com macho e fêmea (a formiga macho, a formiga fêmea).

As armadilhas (por que as outras estão erradas)
  • a) comum de dois gêneros: comum de dois gêneros muda o artigo (o/a), e aqui o artigo não pode mudar.
  • b) biforme (uma forma para cada gênero): biforme tem uma palavra para cada gênero (gato/gata); “formiga” não muda.
  • c) sobrecomum: sobrecomum é nome de pessoa com um artigo só; aqui é nome de bicho.
  • d) heterônimo (o feminino é outra palavra): heterônimo tem uma palavra diferente no feminino (boi/vaca); “formiga” não tem.
Resposta: e) epiceno

Na foto seguinte havia vários. Qual é a legenda correta para ela, de acordo com a norma-padrão? Responda com a letra.
a) Os crocodiloes ficaram quietos.
b) Os crocodilos ficaram quietos.
c) Os crocodilo ficaram quietos.
d) Os crocodilos ficou quietos.
e) O crocodilos ficaram quietos.
Ver a resolução
1

Como pensar: no plural, tudo o que se liga ao substantivo muda junto: artigo, substantivo, adjetivo e verbo.

2

3

A legenda certa é: Os crocodilos ficaram quietos.

As armadilhas (por que as outras estão erradas)
  • a) Os crocodiloes ficaram quietos.: “crocodiloes” está errado: o plural de “crocodilo” é “crocodilos”.
  • c) Os crocodilo ficaram quietos.: o substantivo “crocodilo” ficou no singular.
  • d) Os crocodilos ficou quietos.: o verbo ficou no singular (“ficou”); com vários, é “ficaram”.
  • e) O crocodilos ficaram quietos.: o artigo “o” ficou no singular.
Resposta: b) Os crocodilos ficaram quietos.

Como pensar: sublinhe as duas palavras que a pergunta compara: “uma” e “a”.

2

Artigo indefinido (um, uma): coisa qualquer, que aparece pela primeira vez. Artigo definido (o, a): coisa conhecida, já citada.

3

As armadilhas (por que as outras estão erradas)

  • c) Porque o artigo definido só pode aparecer no fim de um texto.: não existe essa regra.
  • e) Porque “um” mostra algo conhecido e “o”, algo qualquer.: é o contrário.
Resposta: d) Na primeira frase o objeto ainda é desconhecido; na segunda, ele já foi citado e é conhecido.
