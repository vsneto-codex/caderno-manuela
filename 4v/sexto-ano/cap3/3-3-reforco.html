REGRA: REFORÇO: NÚMEROS PRIMOS

O QUE É

Um número primo tem exatamente dois divisores: o 1 e ele mesmo (2, 3, 5, 7, 11, 13…). Um número composto tem mais de dois divisores. O 1 não é primo nem composto: ele só tem um divisor.

COMO FAZER

Para saber se um número é primo, divida pelos primos 2, 3, 5, 7, 11… em ordem. Se alguma divisão for exata, é composto. Pare quando o primo vezes ele mesmo passar do número: aí ele é primo. O crivo de Eratóstenes acha todos os primos de uma vez: risque os múltiplos de 2, de 3, de 5, de 7…; quem sobrar é primo.
