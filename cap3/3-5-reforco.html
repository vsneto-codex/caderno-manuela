REGRA: REFORÇO: SOMAR E SUBTRAIR

O QUE É

Só dá para somar ou subtrair frações quando os pedaços têm o mesmo tamanho, isto é, o mesmo número embaixo.

COMO FAZER

Mesmo denominador: some (ou subtraia) os de cima e repita o de baixo. Denominadores diferentes: primeiro troque por frações equivalentes com o mesmo número embaixo.

OS CASOS

O QUE QUER DIZEREXEMPLO
Mesmo denominadorsome os de cima; o de baixo fica27 + 37 = 57
Diferentesdeixe com o mesmo embaixo12 + 13 = 36 + 26 = 56
Cuidado! Nunca some os de baixo: 12 + 13 não é 25.
