Capítulo 7 · 7.2 Movimentação e giros

Resolução dos exercícios 10.457 a 10.518. Tente resolver antes de olhar!

REGRA: MOVIMENTAÇÃO E GIROS

O QUE É

Para descrever um caminho, dizemos para onde andar e quantas casas. Para descrever um giro, dizemos o tamanho e o lado (direita ou esquerda).

COMO FAZER

Ande uma ordem de cada vez, contando as casas. Nos giros: 14 de volta = virar uma esquina; 12 volta = ficar de costas; volta inteira = voltar a olhar para o mesmo lado.

OS GIROS

O QUE QUER DIZEREXEMPLO
14 de voltavira uma vez (como numa esquina)norte → leste (para a direita)
12 voltafica de costasnorte → sul
34 de voltatrês esquinasnorte → oeste (para a direita)
Volta inteiravolta para onde estavanorte → norte
Cuidado! Girar para a direita é o mesmo sentido dos ponteiros do relógio.

10.517.A pessoa gira no lugar. Para que lado ela fica virada depois do giro? Responda com norte, sul, leste ou oeste.

a)virada para o norte, gira 3/4 de volta para a direita
Ver a resolução
1

Girando para a direita, a ordem é norte → leste → sul → oeste → norte (como o ponteiro do relógio). Para a esquerda, é ao contrário.

2

3/4 de volta = 3 passos nessa ordem: de norte para oeste.

Resposta: oeste
