Desafio

151.
Cada letra representa um número. Se A + A = 480 e A + B = 730, quanto vale B? Responda com um número.
Ver a resolução
1

A + A = 480 quer dizer que duas vezes A dá 480. Então A é a metade: A = 240.

2

Agora, A + B = 730 vira 240 + B = 730. Então B = 730 − 240 = 490.

Resposta: 490
152.

Ver a resolução
1

Comece pelo fim e desfaça cada etapa, de trás para frente: onde somou, tire; onde tirou, some.

5.040 − 500 = 4.5404.540 + 2.950 = 7.4907.490 − 1.400 = 6.090
2

O número pensado é 6.090. Confira refazendo as contas do começo.

Resposta: 6.090
153.
Cada letra representa um número. Se A + B = 1.900, B + C = 2.300 e A + B + C = 2.750, quanto vale B? Responda com um número.
Ver a resolução
1

De A + B + C = 2.750 e B + C = 2.300: tirando B + C do total, sobra A = 2.750 − 2.300 = 450.

2

Como A + B = 1.900, então B = 1.900 − 450 = 1.450.

Resposta: 1.450
