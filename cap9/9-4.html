REGRA: GRÁFICOS

O QUE É

Os gráficos mostram números em desenho, para comparar de um olhar. Cada tipo serve para uma coisa.

COMO FAZER

Leia o título, a legenda e os números dos eixos. Compare as alturas (ou os tamanhos) e responda.

OS TIPOS

O QUE QUER DIZEREXEMPLO
Colunas ou barrascomparar quantidadesvotos de cada fruta
Linhaver como algo muda com o tempotemperatura do dia
Setores (pizza)ver as partes de um todocomo a mesada foi gasta
Cuidado! Olhe a escala do eixo: cada risquinho pode valer 1, 2, 5, 10…

Rumo à prova

12.382.
Uma sorveteria anotou a temperatura às 15 horas em cada dia de uma semana e fez um gráfico de linha: domingo, 33 °C; segunda, 25 °C; terça, 19 °C; quarta, 32 °C; quinta, 15 °C; sexta, 18 °C; sábado, 25 °C. O dono quer saber entre que dois dias seguidos a temperatura MAIS SUBIU, para reforçar o estoque nesse tipo de virada de tempo. Qual é a resposta? Responda com a letra.
a) de sexta para sábado
b) de quarta para quinta
c) de terça para quarta
d) de segunda para terça
e) de quinta para sexta
Ver a resolução
1

Como pensar: num gráfico de linha, a maior subida é o trecho que sobe mais, e não o ponto mais alto. Calcule a mudança de cada dia para o seguinte.

2

domingo→segunda: -8; segunda→terça: -6; terça→quarta: +13; quarta→quinta: -17; quinta→sexta: +3; sexta→sábado: +7.

3

A maior subida foi de terça para quarta (13 graus).

As armadilhas (por que as outras estão erradas)
  • a) de sexta para sábado: a temperatura subiu só 7 graus.
  • b) de quarta para quinta: a temperatura mudou muito, mas caiu 17 graus; a pergunta é a maior subida.
  • d) de segunda para terça: a temperatura caiu 6 graus.
  • e) de quinta para sexta: a temperatura subiu só 3 graus.

Uma sorveteria anotou a temperatura às 15 horas em cada dia de uma semana e fez um gráfico de linha: domingo, 20 °C; segunda, 17 °C; terça, 27 °C; quarta, 34 °C; quinta, 22 °C; sexta, 25 °C; sábado, 29 °C. O dono quer saber entre que dois dias seguidos a temperatura MAIS SUBIU, para reforçar o estoque nesse tipo de virada de tempo. Qual é a resposta? Responda com a letra.
a) de quarta para quinta
b) de sexta para sábado
c) de domingo para segunda
d) de quinta para sexta
e) de segunda para terça
Ver a resolução
1

Como pensar: num gráfico de linha, a maior subida é o trecho que sobe mais, e não o ponto mais alto. Calcule a mudança de cada dia para o seguinte.

2

domingo→segunda: -3; segunda→terça: +10; terça→quarta: +7; quarta→quinta: -12; quinta→sexta: +3; sexta→sábado: +4.

3

A maior subida foi de segunda para terça (10 graus).

As armadilhas (por que as outras estão erradas)
  • a) de quarta para quinta: a temperatura mudou muito, mas caiu 12 graus; a pergunta é a maior subida.
  • b) de sexta para sábado: a temperatura subiu só 4 graus.
  • c) de domingo para segunda: a temperatura caiu 3 graus.
  • d) de quinta para sexta: a temperatura subiu só 3 graus.
Resposta: e) de segunda para terça
